# Individual Hackathon

Part of [Sprint 3: Project Formation](../README.md) (8/16–8/31).

username — add your work directly inside your own folder. See the
[repo root README](../../README.md) for how to submit.

If you're a new collaborator without a folder yet, create one named after
your GitHub username, following the same pattern.
