# Loading animation ideas

## Drifting shape cluster

Use a small group of circles, squares, and diamonds that move on separate paths. The shapes should feel like the system is sorting signals, with restrained motion and no spinner metaphor.

This is the selected treatment for the current MVP.

## Morphing central shape

Use one centered geometric form that changes continuously between a circle, square, diamond, and softer irregular shapes. Each transition should feel fluid, as if the system is testing different interpretations before settling on a result.

Keep the animation monochrome and slow enough to read as deliberate. Reduced-motion mode should show one static shape.

This is a saved alternative for a later iteration.
